Project 00 — Linux + Git + GitHub
Introduction

This project is an introduction to Linux terminal commands, file
manipulation, Git, GitHub, and SSH authentication.

Linux Terminal

In this project, I practiced using the Linux terminal to navigate
directories and manage files.

Some commands used in this project are:

pwd

ls

cd

mkdir

touch

echo

cat

cp

mv

rm

Git

Git is a version control system used to track changes in a project.
It allows developers to save different versions of their work using
commits.

GitHub

GitHub is a platform used to host Git repositories remotely. It
allows developers to store and share their projects online.

Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes
made to a project. This allows developers to understand what changed
and when it changed.

Git also helps protect code because previous commits can be inspected
when something goes wrong. Developers can follow the history of the
project and understand how it developed over time.

Git is also useful for teamwork. Multiple developers can work on the
same project, share their changes, and collaborate using Git.

Git Workflow

The basic workflow used in this project is:

Edit → Add → Commit → Push


The git add command places changes in the staging area, git commit
records the changes in the local repository, and git push sends the
commits to GitHub.

SSH

SSH provides a secure way to authenticate with GitHub.

An SSH key pair contains a public key and a private key. The public
key can be added to GitHub, while the private key must remain secret.

Conclusion

This project helped me practice Linux commands, file manipulation,
Git version control, GitHub repositories, and SSH authentication.
